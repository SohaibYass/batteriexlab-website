# BatterieXLab — Website

Statische Marketing-Website für **batteriexlab.com** (Test-Engineering für HV-Batterien & BMS).

- **Stack:** statisches HTML/CSS/JS, kein Build-Schritt
- **Hosting:** IONOS Deploy Now (automatischer Deploy bei jedem Push auf `main`)
- **Sprachen:** Deutsch (`index.html`) + Englisch (`en.html`)
- **Kontaktformular:** Web3Forms

> Änderungen am `main`-Branch werden von IONOS Deploy Now automatisch veröffentlicht.
